## 🐛 如何提交 Bug 或 功能建议？

如果你在游戏中遇到了报错、物品贴图丢失、兼容性问题，或者有非常棒的新想法，欢迎通过本仓库的 **[Issues](https://github.com/你的用户名/AE2-Pattern-Archive-Issues/issues)** 页面反馈给我！

在提交 Issue 时，请尽量提供以下信息，这将大大加快修复速度：
1. 遇到的具体问题描述。
2. 你的游戏版本（如 1.20.1）。
3. 使用的 Mod 加载器版本（Forge / Fabric / NeoForge）。
4. 游戏崩溃日志（Crash Report）或相关的截图。

## 🎨 关于提供贴图包 / 美术素材

我们非常欢迎并感谢社区玩家为 **AE2 Pattern Archive** 提供材质贴图或模型建议！如果你做了一些好看的素材想要提供给我们，可以直接在 Issues 中发布。

当你向本仓库提交贴图、模型或其他相关游戏素材时，即**表示您明确同意将其免费授权给 `AE2 Pattern Archive` 项目。** 作者有权将这些素材整合、修改并分发到本闭源 MOD 的未来更新中。在此提前感谢所有为本 MOD 添砖加瓦的奉献者！
